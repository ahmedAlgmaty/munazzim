# منظّم — لوحتك الواحدة للوقت والمهام

برنامج إدارة الوقت بتصميم عصري: رؤيتك الشخصية، أهدافك الكبرى، مهام اليوم
والأسبوع والشهر، بومودورو، إحصائيات، وأرشفة تلقائية للمهام المنتهية.

## التشغيل على جهازك (5 خطوات)

1. ثبّت Node.js النسخة LTS من https://nodejs.org
2. افتح مجلد المشروع في الطرفية (Terminal / PowerShell)
3. نفّذ:  npm install
4. نفّذ:  npx prisma db push
5. نفّذ:  npm run dev   ثم افتح المتصفح على  http://localhost:3000

## أوامر مفيدة

| الأمر | ماذا يفعل |
|-------|-----------|
| `npm run dev` | يشغّل البرنامج للاستخدام اليومي |
| `npm run build` ثم `npm start` | نسخة إنتاج أسرع |
| `npx prisma studio` | يفتح قاعدة البيانات في واجهة مرئية |

## ملاحظات

- كل بياناتك تُحفظ محلياً في ملف `db/custom.db` — انسخه كنسخة احتياطية.
- لتغيير قاعدة البيانات لاحقاً عدّل `DATABASE_URL` في ملف `.env`.
- الدليل الكامل للنشر السحابي وGitHub مرفق مع هذه الحزمة.
